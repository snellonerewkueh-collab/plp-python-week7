
# PLP Python Week 7 Assignment

## Assignment: File Handling and CSV Reports

This repository contains two Python programs demonstrating file handling, CSV reading, and report generation.

## Project Files

- **my_notes.py** – Writes, appends, reads, and counts notes in a text file.
- **my_notes.txt** – Stores the four notes generated by my_notes.py.
- **report_builder.py** – Reads learner data from a CSV file and generates a report.
- **hubs.csv** – Contains learner names, hubs, and scores.
- **report.txt** – Contains the generated learner performance report.

## What happens if "a" is changed to "w"?

Changing append mode ("a") to write mode ("w") would erase the existing contents of the file before writing the new note. Therefore, the first three notes would be lost, and only the fourth note would remain.

## Skills Practiced

- Opening files using with open()
- Writing, appending, and reading text files
- Reading CSV files using csv.DictReader
- Converting CSV text values into integers
- Handling FileNotFoundError
- Generating reports from data
